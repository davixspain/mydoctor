Why does this exist?

I was dealing with a stubborn GI case: a melena episode, EGDS, colonoscopy, multiple lab batches, allergic reactions with hard-to-pin-down triggers, months of evolving symptoms across two hospitals and three doctors.

WhatsApp had my photos. My head had the timeline. Obsidian had my notes. Notion had my random observations. None of them talked to each other. Every time I went to the GP I had to reconstruct the case from memory.

So I built MyDoctor for myself. It worked. I cleaned it up, anonymized the defaults, and released it under PolyForm Noncommercial.

What it actually does

Six things, all local, all yours.

📥

Universal ingestion

Photos of lab reports, voice memos, PDFs from specialists, free-form text. Send anything to your private Telegram bot. It catalogs.

🗂️

Longitudinal vault

Obsidian vault that grows with you for years. Visits, Labs, Conditions, Differentials, Symptom diary, Medications, Doctors. All wikilinked.

🧠

Proactive intelligence

Every new input triggers a 60-day pattern scan. Weekly + monthly scheduled reviews. Pings you only when something is genuinely worth saying.

📋

Doctor-ready briefing

A living "Prossima visita" document, always current, ready to print. Numbered priority questions, exams to request, medications to discuss.

🔐

Privacy by design

Data lives on your machine. No cloud, no telemetry, no analytics. The author of MyDoctor never sees your data.

🖥️

Cross-platform

Linux, macOS, Windows native installer. Mobile is via Telegram client (already an app on every phone).

How it works

Three feedback loops. Reactive when you ask. Proactive when something matters. Silent when nothing changed.

1

You message the bot

Photo of a lab report. Voice memo about today's symptoms. PDF from a specialist. Or just: "come sto?"

2

Bot calls Claude with the mydoctor skill

The skill is a single Markdown file that auto-attaches in the project's working directory. Defines the clinical methodology, the output format, the vault conventions.

3

Claude reads the vault and writes back

No embeddings, no vector DB. Markdown files read on demand with native Read/Write/Edit tools. Wikilinks act as graph traversal. For ~50 documents, 100% precision.

4

Scheduled reviews — silently

Sunday 20:00 weekly + 1st of month 20:00 monthly. Pattern detection over time. Telegram push only if something is worth knowing. Otherwise silence.

Install in 3 commands

Cross-platform Python wizard. Linux, macOS, Windows.

# 1. Clone
git clone https://github.com/davixspain/mydoctor.git
cd mydoctor

# 2. Run the wizard
python3 install.py

# 3. Open Telegram, send /start to your bot

The wizard handles everything: detects your OS, checks prerequisites, walks you through @BotFather setup, copies the vault template, installs the Claude skill, registers OS-native services. ~5 minutes.
