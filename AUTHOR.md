## What I build for businesses

### 🩺 Vertical AI assistants
MyDoctor-style tools for specific domains: **veterinary clinics**,
**allergology practices**, **chronic disease management programs**,
**physiotherapy**, **dental chains**. Same architecture, your industry,
your workflow, your branding.

### 🧠 LLM application engineering
Production-grade Claude / GPT / Gemini integrations. Prompt design,
agent architecture, Claude Code skills, MCP servers, tool-calling
patterns. **I write the layer that turns the LLM into a real product.**

### 🔐 Local-first data systems
Knowledge vaults, journaling pipelines, automation layers that respect
privacy and don't lock you into a vendor. Markdown-based, Git-versioned,
filesystem-as-RAG when appropriate, vector DB when it isn't.

### 🖥️ Cross-platform distribution
Python installers that work on Linux/macOS/Windows without exotic
dependencies. systemd / launchd / Task Scheduler integrations.
Single-file or split-package, your call.

### 🤖 Process automation
Telegram / Slack / Discord bots. Schedulers. Integrations between
fragmented tools (Notion ↔ Obsidian ↔ Google Drive ↔ ...). End-to-end
ownership: design + code + docs + ops.

### 🔍 Architecture audits
Code review and architecture audit of existing LLM applications. I tell
you what's broken, what's about to break, what to throw away, what to
keep. Written report. Honest.

### 🎤 Speaking
Talks on local-first AI, personal data ownership, LLM application
